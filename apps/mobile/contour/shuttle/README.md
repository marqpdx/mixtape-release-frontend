# Shuttle Contour handoff bundle

Approved findings fields, pinned at 0.1.0. Packaged locally for the CTO to carry
to `puddlejump/reference/contour/shuttle/`; these files have not been published
to Puddlejump or merged into its manifest by this session.

Each Shape includes schema, template, extraction guidance and validation
guidance. `manifest.fragment.yaml` supplies the additive manifest entries.
The Strategy includes its YAML contract and reasoning companion.

The implementation's schema is bundled identically in Core and packages/api.
Do not edit any published version in place; follow Contour versioning rules.
