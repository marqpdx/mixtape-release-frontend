The loop is four words: **push some, note what happens, adapt, carry on.** One step wider each time (a larger remit, one more permission, one more agent); what happened written where the work is recorded; the rule or tool adjusted; pulled back cheaply if it went wrong.

It is *Manual first*'s loop applied to capability as a whole. What makes it safe now is a server whose state is declared and provable, agents that act as named people with every call recorded, and a terminal where many sessions stay in view. Still a draft.
