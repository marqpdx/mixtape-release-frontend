# Your Group Member Profile

This page is your personal edit surface inside a group context. It is meant for updating your own member profile without leaving the group workflow entirely.

## What you can do here

- Edit your own profile details
- Make changes while staying anchored to the group you came from
- Return directly to the group when you are finished

## How this page is different from the public profile

This is an **edit** surface, not a public profile display page. It is for changing your own information. The public profile pages under `/member/...` are for viewing a member-facing presentation of that information.

## Typical flow

1. Open the page from inside a group.
2. Update the profile fields you need to change.
3. Save your changes.
4. Use the return button to go back to the group.

## Current limitations

- The page is intentionally minimal. It is a utility surface wrapped around the profile editor rather than a full member dashboard.
- Group-specific profile expectations are still shaped by the underlying member profile system, not by a separate group-only profile model.

## Related features

- **Member Surfaces** — the broader personal pages for hub, profile, library, and settings
- **Groups** — the community context you return to after editing
