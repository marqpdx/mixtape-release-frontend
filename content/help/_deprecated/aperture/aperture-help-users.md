# Aperture

Aperture is a focused work surface for specialized Mixtape flows. If you are here, you are likely using a targeted tool or internal workflow that sits outside the main member dashboard.

## What to expect

- A narrow interface built for one operational task
- Fewer navigation affordances than a general-purpose member page
- Page-specific controls that assume you are already inside a defined workflow

## Working in Aperture

1. Treat the page title and visible controls as the source of truth for the specific task.
2. Complete or review the focused action the page is asking for.
3. Return to the broader member or admin surface when the task is done.

## Current limitations

- Aperture is intentionally narrow and may not provide broad orientation or discovery cues.
- Help coverage here starts at the subsystem level; page-specific instructions can be added later as the workflow stabilizes.

## Related features

- **Admin** — Some Aperture flows may be operator-facing.
- **Dashboard** — You will usually enter Aperture from another work surface rather than staying here full-time.
