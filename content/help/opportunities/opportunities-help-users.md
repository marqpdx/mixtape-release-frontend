# Opportunities

Opportunities is a private workspace for finding and reviewing current work possibilities without handing judgment over to an automated system.

## What you can do here

- Record the roles, technologies, arrangements, and constraints that matter now
- Keep the résumé version informing the search visible
- Inspect the focused searches Mixtape will run
- Search approved external sources and retain the resulting evidence
- Mark findings as interesting, pass on them, or request fuller source details
- Draft and edit a grounded cover letter before downloading it as a PDF

## Key concepts

**Search profile** — A versioned statement of what you are looking for now. It is informed by your résumé, but it also records current preferences and exclusions that a résumé cannot express.

**Search lane** — One focused query within the broader profile. Separate lanes help Mixtape find adjacent kinds of work without relying on one oversized query.

**Working Set** — The reviewable results of one search run, preserved with the profile version, source, query details, and outcome counts that produced it.

**Shallow result** — The bounded summary returned during initial discovery. Request full details only for a listing that deserves closer attention.

## How to run a search

1. Open the search profile and identify the résumé version informing it.
2. Add one or more focused search lanes.
3. Record strong technologies, domains, seniority, work arrangements, and exclusions.
4. Save the profile and inspect the searches shown under **Next search**.
5. Select **Search Dice**.
6. Review the resulting Working Set before requesting full details or taking action.
7. For a suitable listing, select **Prepare application**, review every claim in the suggested letter, and edit it as needed.
8. Download the PDF, then open Dice to complete the authenticated application yourself.

## Important boundaries

- Search findings are provisional and require human review.
- Fit labels are preliminary signals, not employment decisions.
- Mixtape does not apply for a role automatically.
- Recruiter names or email addresses found in listing text remain unverified until you confirm them.
- Verify source details directly before corresponding with an employer or recruiter.

## Current limitations

- Dice is the first opportunity source.
- Résumé selection is recorded by label and version while managed résumé assets are still being completed.
- Cover letters are grounded in the listing and the associated opportunity profile; they do not yet read a managed résumé asset directly.
- Deeper fit analysis and correspondence tracking will arrive in later phases.
