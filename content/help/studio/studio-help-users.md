# Studio

Studio is a focused workspace inside Mixtape. It gives a group or circle a more intimate surface for shared context, participation, and ongoing work without sending you back through broader navigation every time.

## What you can do here

- Enter a group or circle workspace directly
- Rejoin the current conversation and shared context for that space
- Move between the parent group view and the more focused studio view

## Key concepts

**Studio** — A focused workspace for a specific community space.

**Circle studio** — The studio view for a nested circle inside a group, with a tighter scope than the parent group.

## Current limitations

- Studio help is currently an overview. Some tasks inside studio may still rely on help from the related group, writing, or library surfaces.

## Related features

- **Groups** — Studio lives alongside the broader group surface.
- **Writing** — Writing and publishing flows may continue from within a studio context.
- **Stackroom** — Shared files and collection work may still send you into library surfaces.
